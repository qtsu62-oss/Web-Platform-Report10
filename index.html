لغة CSS وتصميم صفحات الويب

المقدمة

أصبحت المواقع الإلكترونية من أهم وسائل التواصل والحصول على المعلومات في العصر الحديث، إذ نستخدمها في التعليم والعمل والتسوق والترفيه. وكي يكون الموقع ناجحاً لا بد أن يتميز بتصميم جيد وألوان متناسقة وخطوط واضحة تساعد المستخدم على قراءة المحتوى بسهولة.

ومن هنا تأتي أهمية لغة CSS التي تُستخدم في تصميم صفحات الويب والتحكم في شكلها ومظهرها، فهي تساعد على تغيير ألوان النصوص والخلفيات واختيار أنواع الخطوط وأحجامها وتحديد المسافات بين العناصر، إضافة إلى تنظيم شكل الصفحة بما يتناسب مع أجهزة الكمبيوتر والهواتف المحمولة.

عرض الموضوع

1. ما هي CSS؟

CSS اختصار لعبارة Cascading Style Sheets وتعني «أوراق الأنماط المتتالية». وهي لغة تنسيق تُستخدم للتحكم في المظهر الخارجي لصفحات الويب، بينما تُستخدم HTML لإنشاء هيكل الصفحة وإضافة المحتوى مثل العناوين والفقرات والصور.

تعتمد CSS على كتابة قواعد تتكون من ثلاثة أجزاء: المحدد (Selector) وهو العنصر المراد تنسيقه، والخاصية (Property) وهي الجزء المراد تغييره مثل اللون أو حجم الخط، والقيمة (Value) وهي الشكل المطلوب. مثال:

h1 {
  color: blue;
  font-size: 30px;
}

فالمحدد h1 يستهدف العناوين الرئيسية، والخاصية color مسؤولة عن لون النص، والقيمة blue تجعل لون العنوان أزرق، والخاصية font-size مسؤولة عن حجم الخط، والقيمة 30px تعني 30 بكسل.

2. طرق استخدام CSS

الطريقةالشرحمثال
داخل العنصر (Inline CSS)كتابة التنسيق داخل عنصر HTML نفسه بالخاصية style<p style="color: red;">
داخل الصفحة (Internal CSS)كتابة القواعد داخل وسم style الموجود عادة في جزء head من الصفحة<style> p { color: green; } </style>
ملف خارجي (External CSS)كتابة القواعد في ملف مستقل بامتداد css ثم ربطه بالصفحة، وهي مناسبة للمواقع متعددة الصفحات لأنها توحّد التصميم وتسهّل تعديله<link rel="stylesheet" href="style.css">

3. تغيير الألوان والخطوط

للتحكم في الألوان نستخدم الخاصيتين التاليتين:
• color : لون النص
• background-color : لون الخلفية
ويمكن كتابة اللون باسمه، أو بالرموز السداسية للون الأحمر مثلاً. وللتحكم في الخطوط نستخدم الخصائص التالية:

• font-family : نوع الخط
• font-size : حجم الخط
• font-weight : سمك الخط
• font-style : جعل الخط مائلاً
• text-align : محاذاة النص
• line-height : المسافة بين الأسطر

body {
  background-color: #F2F2F2;
  color: #333333;
}
p {
  font-family: Arial, sans-serif;
  font-size: 18px;
  line-height: 1.6;
}

يغيّر هذا المثال خلفية الصفحة إلى رمادي فاتح ولون النص إلى رمادي داكن، ويحدد الخط Arial بحجم 18 بكسل مع زيادة المسافة بين الأسطر لتسهيل القراءة.

4. المسافات وترتيب العناصر

من الخصائص المهمة للتحكم في المسافات والحدود:
• margin : المسافة الخارجية حول العنصر
• padding : المسافة الداخلية بين المحتوى وحدود العنصر
• border : الحدود حول العنصر

أما لترتيب العناصر فتُستخدم أداة Flexbox لترتيبها في صف أو عمود وتوزيع المسافات بينها، وأداة CSS Grid لإنشاء تخطيطات تعتمد على الصفوف والأعمدة، مثل عرض مجموعة من المنتجات أو الصور في شبكة منظمة.

.container {
  display: flex;  justify-content: center;  gap: 20px;
}

5. التصميم المتجاوب

يجب أن يعمل الموقع بشكل جيد على أجهزة الكمبيوتر والأجهزة اللوحية والهواتف المحمولة، وتوفر CSS لذلك خاصية Media Queries التي تغيّر التصميم حسب عرض الشاشة:

@media (max-width: 600px) {
  h1 {
    font-size: 24px;
  }
}

في هذا المثال يصبح حجم العنوان 24 بكسل عندما يكون عرض الشاشة 600 بكسل أو أقل.

6. مثال تطبيقي

لنفترض أننا نريد تصميم صفحة بسيطة لمكتبة إلكترونية، بخلفية فاتحة وعنوان أزرق ونصوص واضحة وصندوق للمعلومات:

body { background-color: #F5F5F5;  color: #333333;  font-family: Arial, sans-serif; }
h1 { color: #006699;  text-align: center;  font-size: 30px; }
.card { background-color: white;  padding: 20px;  margin: 15px;
  border: 1px solid #CCCCCC;  border-radius: 8px; }

في هذا المثال تتغير خلفية الصفحة إلى رمادي فاتح، ويصبح لون النصوص داكناً لتسهيل قراءتها، ويظهر العنوان بالأزرق في منتصف الصفحة، ويُنشأ صندوق أبيض للمعلومات بمسافات وحدود وزوايا مستديرة.

7. الخاتمة

تُعد CSS من أهم التقنيات المستخدمة في تصميم مواقع الويب، فهي تساعد على التحكم في الألوان والخطوط والأحجام والحدود والمسافات وتنظيم العناصر، وتجعل التصميم مناسباً لمختلف الأجهزة. ومن نصائح التصميم الجيد اختيار ألوان متناسقة وخطوط واضحة وترك مسافات كافية وتجربة الموقع على أجهزة مختلفة. وتعلّم CSS خطوة أساسية لكل شخص يرغب في تصميم وتطوير المواقع الإلكترونية.
